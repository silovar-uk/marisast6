FRAME ADVANTAGE / PRESSURE MAP

有利だから、何が埋まる？

ガード時のプラスフレームを、次の打撃が連続ガードになるのか、4F暴れを潰すのか、相打ちになるのか、割り込まれるのかまで分解します。数字上は成立しても技が届かない「距離の穴」も別に確認します。

「埋まる」は隙間0F以下の連続ガードに限定します。隙間はあるが4F暴れに勝つ連携は「暴れ潰し」と呼び分けます。

01 / WHAT PLUS MEANS

有利は、先に動ける時間。

ガード時＋4Fとは、マリーザが相手より4フレーム早く動き始められるという意味です。早く動ける時間を打撃、投げ、前歩き、ガード、再度の溜めへどう使うかが攻めの本体です。

「反撃されない」と「有利」は別です。−2Fは通常の4F技による確定反撃を受けませんが、こちらのターンでもありません。不利幅が4F以上、表記では−4F以下なら、距離が合う発生4F技で確定反撃を受けます。

PLUS

＋1F以上

マリーザが先に動けます。ただし次の技が遅い、届かない、無敵技やアーマーに負ける場合があります。

SAFE

不利だが反撃なし

相手が先に動いても、最速技より不利幅が小さければ通常打撃の確定反撃はありません。

PUNISHABLE

確定反撃を受ける

不利幅、相手の最速技、実際の距離が一致した時に確定反撃が成立します。

02 / TIGHT OR OPEN

埋まるかは、次の技まで計算する。

有利フレームだけでは連携の隙間は決まりません。次に出す技の発生を合わせ、相手が動ける時間が残るかを見ます。次の技を遅らせた分だけ隙間は増えます。

FRAME GAP 隙間F ＝ 次の技の発生F − 有利F − 1

隙間0F以下は連続ガード。最速4Fを基準にすると、1〜2F空きは暴れ潰し、3F空きは相打ち、4F以上は割り込み可能です。

TRUE BLOCK STRING

＋4F → 発生5F

隙間0F

完全に埋まる連続ガード。相手は通常行動を挟めません。

FRAME TRAP

＋4F → 発生6F

隙間1F

連続ガードではありませんが、相手の4F打撃より先に当たります。

TRADE

＋4F → 発生8F

隙間3F

相手の4F打撃と同じタイミングで攻撃判定が出ます。

INTERRUPTIBLE

＋4F → 発生9F

隙間4F

相手の4F技が先に当たり、暴れ潰しにはなりません。

計算上の隙間：0F 完全に埋まる（連続ガード）

03 / TIME AND DISTANCE

時間が埋まっても、距離が空く。

計算上は埋まっていても、ガードバックで相手が離れ、次の技が届かなければ連携は成立しません。溜めグラディウスやファランクスの後は、投げや短い小技が届くかを別に確認します。

届かない場合は、N中、再度のグラディウス、前歩き、相手の暴れを待つガードへ切り替えます。有利フレームは行動を保証せず、選択肢を増やす材料です。

CHECK 1

最速4Fを録画する

有利技後の打撃が勝つ、相打ち、負けるのどれになるかを確認します。

CHECK 2

ガードを録画する

次の技が連続ガードか、隙間がある暴れ潰しかをフレームメーターで確認します。

CHECK 3

後ろ歩きと無敵技

投げや短い技が届かない距離、無敵技やアーマーに負ける選択を確認します。

何を押すと、何に勝つか。

打撃は暴れ、投げはガード、ガードは無敵技への回答になります。対空は別の判断で、第一候補はワンボタングラディウス。SA2、しゃがみ強、空対空は距離や角度に応じた補助候補です。

04 / PLUS MOVES

ガードされて有利な技。

現行技データからガード時にプラス値を持つ技だけを自動抽出します。最大溜め時だけ有利になる技は条件を含めて表示します。

現行値が未計測のクアドリガや、旧参考値しかない項目は一覧へ混ぜません。
