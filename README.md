# MODERN MARISA LAB

Street Fighter 6「モダンマリーザ」の個人用リファレンス。技を数表として読むのではなく、**時間の帯**と**つながり**、実戦の**状況**から判断できるように再設計しています。

## 公開ページ

- `index.html` — 技。公式モダンフレームデータ84行を系統で重ね、帯・表・詳細・つながりで確認する
- `situations.html` — 状況。既存の状況逆引き・詳細起き攻め・作戦ノートを統合した48件から候補技へ移る

## データ基準

- 公式スナップショット: `data/official-modern.json`
- 取得日: 2026-09-28
- SHA256: `019bf6e85747c85052d1f2aada5c7ff3261a08ea5dea795064f6816c2b2c1d54`
- モード: モダン
- 行数: 84

公式表にない「キャンセル受付フレーム」「距離で届くか」「空中追撃成立」は推測で補いません。旧攻略ノート由来の定番ルートは「資料由来」として分離し、再確認を前提に表示します。

## 使い方

- 初期表示は「必殺技」・弱グラディウス
- 「すべて」で公式84行を確認
- 帯を横になぞると同じフレームの状態を比較
- 詳細の「通常ヒット / カウンター / パニカン / ラッシュ / ガード」でつながりを切り替え
- 確反ものさしで相手の不利フレームに届く発生だけを強調
- 状況カードの「技で比べる」から候補技だけを強調した技ページへ移動
- 旧作戦ノート `marisa-decision-notebook-v1` がある場合だけJSON書き出しボタンを表示

キーボードは `/` で検索、上下で技移動、左右で同系統の版移動、`1`〜`5`で当たり方切替、`Esc`でシート/状況フォーカス解除。

## URL

`index.html?move=<技ID>&cond=<n|c|pc|dr|g>&view=<band|table>&cat=<種類>&focus=<状況ID>`

旧 `moves.html?move=<技ID>` は同じ技IDを保ったまま新しい技ページへ移動します。外した旧ページは技ページへ、`decision.html` は状況ページへ移動します。

## データ構成

- `data/official-modern.json` — 公式表84行の生スナップショット
- `data/lab-data.js` — 技ID、使いどころ、派生、資料由来ルート、48状況、8場面
- `lab-core.js` — Node/ブラウザー共用の純粋な解釈・計算関数
- `lab.js` / `lab.css` — 表示と操作
- `tools/validate.mjs` — 依存なしのデータ/公開契約検査

## ローカル確認

```bash
python -m http.server 8128
node --check lab-core.js
node --check lab.js
node tools/validate.mjs
```

受け入れQAは引継ぎ資料の `qa.mjs` を使用します。
